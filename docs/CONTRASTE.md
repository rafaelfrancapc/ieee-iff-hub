# Contraste e preservação dos logos

Os arquivos foram copiados sem alterações de cor, inversão, filtros ou redesenho. Todas as marcas dos capítulos usam uma base branca constante nos dois temas. Isso evita perder os textos pretos da CS e da PES no tema escuro.

## Interface

| Par | Claro | Escuro |
| --- | --- | --- |
| Texto principal / página | 13,21:1 | 15,70:1 |
| Texto secundário / painel | 5,89:1 | 7,29:1 |
| Links / página | 5,93:1 | 9,80:1 |
| Texto do botão / azul IEEE | 6,52:1 | 6,52:1 |

As razões são calculadas a partir das cores definidas, sem amostrar bordas antialiasadas. Não representam uma auditoria completa de acessibilidade.

## Logos

| Marca | Contraste relevante sobre a base branca, em ambos os temas | Tratamento |
| --- | --- | --- |
| Ramo | Azul principal / cabeçalho: 5,03:1 no claro e 3,14:1 no escuro; símbolo branco / azul: 5,03:1 | Original no cabeçalho; elementos brancos internos mantidos |
| CS | Texto preto / branco: 21:1 | Original em base branca; laranja 2,02:1 e separador cinza 2,36:1 preservados |
| PES | Texto escuro / branco: aproximadamente 16,3:1 | Original em base branca; verdes claros do símbolo mantidos |
| RAS | Vermelho / branco: 8,83:1; roxo / branco: 11,69:1 | Original em base branca |
| EMBS | Roxo / branco: 8,88:1; azul / branco: 6,60:1 | Original em base branca |

A base azul-escura do logo geral tem pouca separação do cabeçalho escuro (1,11:1); a silhueta azul principal e o símbolo branco mantêm a identificação. O laranja da CS e alguns verdes claros da PES têm contraste menor no desenho original. Eles não foram recoloridos para simular uma aprovação geral. O nome do capítulo e a função do link também aparecem em texto da interface, com contraste próprio e independente da imagem.

A orientação WCAG distingue logotipos do texto de interface e recomenda um controle equivalente legível quando a marca é um link: [W3C, contraste mínimo e logotipos](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

Azul de referência: #00629B, publicado nas [diretrizes de identidade IEEE](https://entrepreneurship.ieee.org/wp-content/uploads/2021/01/2021-Powered-by-IEEE-Visual-Identity-Guidelines-Interactive.pdf).

As medições das cores predominantes estão em CONTRASTE.json. A conferência visual considera os tamanhos de uso, além das razões numéricas.
